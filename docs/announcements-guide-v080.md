# v0.8.0：首次引导、公告与品牌

## 使用方式

管理员在「帮助与设置 → 公告管理」新建或编辑公告。填写标题和纯文本正文，保存草稿不发送消息；点击「保存并发布」后，全部已批准成员可见。成员在下一次登录或恢复网页登录时优先看到未读公告，再显示首次使用引导。公告和个人预约通知继续汇总到顶部「通知」。

公告弹窗的「已阅读」才记录已读；「稍后查看」和 Escape 关闭不会记录已读，下次登录仍提醒。历史通知提供分页和已读/未读状态，可逐条查看或全部标为已读。同一个账号换浏览器、换调用 Key 仍沿用服务端状态。一次登录最多自动展示10条未读公告，其余在历史通知中查看。

管理员保存已发布公告的修改时，成员仍看到原发布快照。再次发布生成新的通知版本，原读者也会收到未读提醒；相同版本的重复发布请求不会重复产生通知。撤回隐藏该篇公告的发布历史，保留管理员草稿、快照和审计。撤回后重新发布会恢复历史可见性并产生新版本。

首次引导的自动展示记录与“当前版本阅读确认”分开：一个账号自动展示一次，关闭即可继续工作；之后登录、角色变化及版本更新都不再强制跳转。顶部引导按钮持续存在，内容随版本维护，更新只显示入口标记。已有 `guide.ack` 记录的账号直接视为已看过。没有历史确认/展示证据的旧账号升级后最多提示一次。

## 权限与接口

新账密模式的所有 `/api` 写操作继续使用会话、CSRF 和精确 Origin 校验；兼容模式沿用原 Bearer 管理身份。公告编辑、发布及撤回只允许管理员，事务内复核当前身份。普通成员不能读取草稿。未批准账号不接收全员公告；批准后可以查看在架的历史公告。

| 接口 | 用途 |
| --- | --- |
| `POST /api/guide/seen` | 原子领取账户首次展示标记，不依赖版本；返回 `first_visit` |
| `GET /api/guide` | `first_visit` 控制一次弹窗；`needs_attention` 只表示当前版本未确认 |
| `GET /api/announcements?limit=50&offset=0` | 管理员草稿与发布状态列表 |
| `POST /api/announcements` | 新建草稿，标题1–100字符，正文1–6000字符 |
| `PATCH /api/announcements/{id}` | 更新草稿，需 `expected_revision` |
| `POST /api/announcements/{id}/publish` | 发布当前版本；需 `expected_revision`，重复版本幂等 |
| `POST /api/announcements/{id}/withdraw` | 撤回，需 `expected_revision` |
| `GET /api/notifications?limit=40&offset=0` | 合并个人通知和已发布公告，含总数、未读数及未读公告 |
| `POST /api/notifications/{id}/read` | 只记录当前账户已读；不能改其他人的状态 |
| `POST /api/notifications/read-all` | 只标记当前已可见的消息，后续新发布仍为未读 |

输入为纯文本，展示时转义；不执行正文 HTML、脚本或远程内容。修订冲突返回409并保留编辑输入，需要刷新核对；未找到公告/消息返回404，越权403。接口及日志不保存正文到审计字段。通知是站内功能，不是邮件、操作系统推送或模型执行器。

## 数据与迁移

只增加 `announcements`、`announcement_publications`、`announcement_reads` 三表。已有个人通知、用户、Key、请求、账本不重建、不删除。发布快照不可变，已读状态按发布版本与用户ID存储；新增成员不需要批量复制历史通知。

生产更新先核对当前部署及在途任务，完成一致性数据库备份、旧 release/unit/vhost 备份，再在维护窗口切换并验收。回退代码时保留新增表和活数据库，不用旧备份覆盖新用量。本文及本地验证不表示已在真实云端执行迁移。

## 已确认的品牌

用户确认采用 C「网关 VR」。网站标志使用图像生成工具产出的透明 PNG，保留原像素；标签页使用同一视觉方向的小尺寸 SVG 简化稿，避免载入大型位图作为 favicon。

- `gateway/static/brand-mark.png`：选定图形，SHA256 `375d881389744d1b9e625f53e0a36eea350bf109aaee48883371028dbeae35fc`。
- `gateway/static/favicon.svg`：保留 VR、断开边框、青绿节点及金色中心，代码绘制，无外部字体或资源。
- 页头声明 SVG favicon 与 PNG fallback，带版本参数。浏览器仍缓存旧图时可刷新标签页。

输入参考图和其余候选仅保存在本机忽略目录；公开源码不包含实验室横幅原图或真实部署资料。生成提示要求以参考的 VR 结构结合奶油色、海军蓝、青绿和金色工作区设计，不添加实验室全称或官方认证文字。

## 验证

后端覆盖公告草稿隔离、权限/CSRF、不可变发布、幂等、修订冲突、撤回、个人已读、历史分页、未来通知仍未读，以及首次引导不随版本或Key重复。浏览器使用真实本机后端与合成数据，覆盖编辑发布→下次登录→稍后查看→重登→已读→重登不弹→修改再发布→撤回；验证正文脚本只作为文字展示、品牌图片加载和 favicon HTTP/MIME，并检查桌面与窄屏弹窗边界。

2026-10-26 本地结果：全套118项 Python 测试通过；前端契约、两条真实 Chromium 流程及通知故障检查共9项通过。视口1440×1000、1366×768、390×844；新成员首次登录的公告优先顺序和已读公告不重复提示已实测。引导同步、JavaScript 语法、公开文件及品牌字节指纹检查通过。保持现有锁定依赖，TestClient 的上游弃用提示未因此触发升级。没有连接真实模型、发布生产公告或执行云端迁移。

# 权限与工作流

本文件描述通用本地实现，所有资产信息均来自合成样例或操作者自己保存在忽略目录的快照。

| 能力 | 管理员 | 运行操作员 | 调用者 | 审计员 |
|---|---|---|---|---|
| 调用模型 | 用户/Key授权交集 | 同左 | 同左 | 禁止 |
| 查看自己任务/产物 | 是 | 是 | 是 | 无调用任务 |
| 发放/吊销Key、更新角色/授权 | 是 | 禁止 | 禁止 | 禁止 |
| 查看配置、资源及脱敏元数据 | 是 | 是 | 仅自己 | 是 |
| 操作批准的模拟profile | 是 | 按profile grant | 禁止 | 禁止 |
| 修改策略意图/预算、人工对账 | 是 | 禁止 | 禁止 | 禁止 |
| 任意宿主命令/真实Docker操作 | 无此接口 | 无此接口 | 无此接口 | 无此接口 |

API Key 用 `secrets.token_urlsafe` 产生，只存SHA256。角色不隐含模型调用授权。撤回用户模型授权、停用账号或撤销Key即时生效；已登记的运行操作在执行前再次检查权限。管理员也不能直接下载其他用户的任务产物。

文本流程：Key鉴权 → 模型授权 → 请求参数+来源hash → 幂等检查 → 用户/Key双层预算预留与限流 → 绑定profile/hash → 标记派发 → SDK调用 → 校验真实usage → 同事务结算/释放。重复请求返回原响应；超时和无usage冻结待对账。进程重启不重提已派发的不确定请求。

视频流程：鉴权/归属 → 同事务保存请求与预留 → 有界持久化队列 → 按用户最近服务时间调度 → 模拟并发1 → 保存模拟结果并一次结算。只能可靠取消尚未派发的队列任务；不能把停止容器当成取消计算。模拟产物用JSON标识，不伪造MP4或进度百分比。

运行流程：操作员提交固定profile与配置hash → 独立模拟代理鉴权/白名单/防重放 → draining拒绝新派发 → 等待已接收任务/未知请求归零 → 停旧实例 → 检查模拟GPU和端口互斥 → 模拟启动/健康检查 → 提交路由；失败恢复旧路由。真实执行器尚未实现，所有模拟操作明确标记来源。

`always_on`、`on_demand`、`manual`、`idle_stop` 是期望策略，与观察状态分开。自动预热/空闲停止未启用；未就绪调用返回503。指定GPU不是显存硬配额，真实共享和峰值容量必须另行实测。

首版资产/镜像/profile目录为只读代码；账号、授权、账本、任务、操作及审计用SQLite WAL持久化，单worker持进程锁。Web与模拟代理共享本机数据库，这是事务演练，不是生产隔离。上游凭证不传给控制子进程。

管理页Key仅在页面内存中保存；Host/Origin检查、CSP、输入上限和对象归属由后端执行。数据库中的文本响应正文用于幂等重放，需要在正式使用前设置保留和脱敏策略。没有公网发布配置。

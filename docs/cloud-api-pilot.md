# 受限云端文本试运行

v0.6.0 在既有云预发布状态上增加显式 `--cloud-api` 模式。保留原数据库、成员、Key 和额度；不建立模拟运行实例，不启动运行控制子进程，也不接入 Docker。`--cloud-preview` 的推理关闭行为保持不变。

这仍是项目组受限试运行。网页登录沿用当前页面内存中的高熵 Key；独立网页登录会话尚未实现。管理员凭证只管理平台，只有普通成员的 Key 可以访问文本推理协议。SSE、工具调用、Responses、Anthropic Messages、视频执行、模型启停和服务端 harness 都未开放，不能据此声称完整兼容任何客户端。

## 固定配置

运营者维护不含凭证的 JSON，例如：

```json
{"alias":"research-text","served_model":"example-engine","base_url":"http://127.0.0.1:28080/v1"}
```

仅支持固定 IPv4 loopback 地址、明确端口和 `/v1`。alias 必须已在现有模型目录中登记为文本模型。请求体不接受 Base URL、上游 Key 或任意 SDK 参数。HTTPX 不使用环境代理，不跟随重定向，不自动重试，限制响应体和时间；没有模型 SDK 的回调、自动 provider 选择或 fallback。

**服务器 Bash，完成上游部署和认证隧道验收后**，使用既有虚拟环境启动：

```bash
.venv/bin/python -m gateway serve --state /var/lib/token-controller --port 18765 \
  --cloud-api --upstream-config /etc/token-controller-api/upstream.json \
  --public-origin https://models.example.test
```

这条命令仅启动网关，绑定本机地址。它要求已有云预发布标记，不允许通过删除标记回退到演示模式。生产地址与实际上游信息只保存在运营者私有配置中。

模板为 `deploy/token-controller-cloud-api.service`、`deploy/nginx/token-controller-api.conf`。在现有机器上先备份、审阅差异、验证候选配置与回滚，再启用。不要覆盖其他站点、重复创建整套数据库或重装已有依赖。新代码不改变依赖锁与数据库 schema。

## 上游凭证登记

`POST /api/upstream/credential` 仅接受管理员 Bearer 凭证和 JSON `value`。应由已登录的校内运维终端直接读取私有上游 Key 文件，通过校验证书的 HTTPS 发送；不要打印 Key、把它放进命令参数、聊天或公开文件。

服务先用候选 Key 做只读 `/models` 探测，确认实际 served_model 后，才原子保存到状态目录的 `upstream-api.key`。POSIX 权限要求为当前服务用户拥有的单链接普通文件、0600；不跟随凭证文件软链。接口不接受保存路径，不返回 Key。审计仅记录操作者、alias 与探测结果。有在途或待对账请求时不能轮换凭证。

## 成员调用与计量

管理员创建普通成员 → 分配目录模型与预算 → 发放独立 Key → 成员获取 `/v1/models` → 调用非流式 `/v1/chat/completions` → 查看自己的用量。

有效模型权限为账户与 Key 授权的交集。取消授权、停用账户、吊销 Key、移除登记都应阻止后续调用。管理员 Key 即使具有模型授权，也不能调用 `/v1`。

每次文本请求按 UTF-8 字节上界、消息开销和最大输出预留额度，保守上界超过 16384 时拒绝。当前一点等于一个已结算 token，并不表示实际电费或人民币成本。上游 usage 必须包含非负整数输入、输出及一致的合计；按真实值结算并释放差额。预留估计可能比实际 token 明显偏大。

网关同时只派发一个文本请求，通过 SQLite 原子事务准入；不同成员同样受此限制。满载返回429，不建立无界推理等待队列。预约登记继续独立，不执行或冻结推理额度。此限制无法统计其他直接调用上游的应用，整体模型容量还需单独测量。

同一 Key 重试使用同一个 `Idempotency-Key`。已完成请求返回原结果，不再次调用或扣费；修改输入必须更换 ID。模型请求发出后，超时、无效 usage 或断线会保留预留并进入待对账，阻止新的文本派发，直到管理员核实。提交前只读探测失败则按未派发结算为零。进程重启不盲目补发未知请求。

Nginx 保留 HTTPS、IP/全局速率、连接数和请求体限制。新模板中 `/api/me` 使用通用边缘限制，取消专用于它的额外低速登录桶，减少日常页面导航误触限流的机会；真实页面操作是否仍有429须现场验证。调用端仍可能收到正常的成员配额或模型容量429，不能将它们统一当成前端错误。

## 验证边界

测试使用合成凭证、临时数据库与模拟上游；覆盖管理员/成员分离、授权和额度、撤销、原子并发、幂等结算、未知提交对账、重定向拒绝与已有预发布隔离。前端契约测试不是浏览器视觉实测。真实云端上线、实际模型生成、校园网外调用及客户端兼容，均须单独执行验收。

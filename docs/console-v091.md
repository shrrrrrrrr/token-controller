## 校园素材

用户照片与实验室标志保留在忽略的运行状态目录 `site-assets/`，不随公开源码发布。运营者确认使用范围后可安装以下两个固定文件：

- `campus.jpg`：校园照片，最多 2 MiB
- `lab-logo.png`：透明实验室标志，最多 2 MiB

`/site-assets/` 只提供上述两个明确用于公开展示的文件，不是状态目录的通用文件下载接口。拒绝符号链接、硬链接及超大文件。缺少照片时使用浅蓝背景，缺少标志时隐藏该图片；登录表单仍可用

本次本地预览使用用户提供的北航照片及去除棋盘背景后的标志。字体、阅读层与交互参考用户指定的 PBL 风格规范，按本项目要求保留圆角按钮和 VR 徽章

## 调用记录

本次没有清理历史数据。`requests.response` 保存完整模型回复以支持幂等重放；请求元数据、Token 统计、用量账本分别保存。以后若增加保留期限，应同时明确回复正文、调用明细和幂等窗口的期限，并验证累计用量、未结请求及账本不会因清理改变

## 验证

运行账号、引导、模型控制相关测试，执行全部 Python 回归与角色引导/公开目录检查，并用真实浏览器验证桌面、窄屏、短屏、账号菜单、错误原密码、两步改密和重新登录。本地模拟通过不代表云端部署或真实 GPU 切换完成

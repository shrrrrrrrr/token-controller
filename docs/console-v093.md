# v0.9.3 · 全站背景设置

管理员在「工具与设置 → 背景设置」选图后点击「应用到全站」。设置保存在服务端数据库，登录页及所有成员使用同一背景；已打开的页面每 10 秒检查一次，重新回到页面时也会同步。图片加载完成后替换背景，不重载页面、不重绘表单

背景覆盖整个视口，包括侧栏、顶栏及页脚。内容面板保留约 88% 的底色，登录窗口约 80%；正文和控件的文字不降低透明度。侧栏按钮取消位移、缩放、动画和阴影反馈，保留选中状态与键盘焦点

## 图片登记

照片由运营者选择，原图不改动、不提交公开源码。Windows 可先用 `tools/prepare_background_images.ps1` 生成最长边1920像素的网页副本和480像素缩略图，再登记到运行状态目录；列表使用缩略图，避免同时解码全部高清原图。安装命令默认只检查，加 `--apply` 才复制：

```bash
python tools/install_background_gallery.py --source /path/to/background-photos --state .state/preview --apply
```

支持每张最多 12 MiB 的 JPEG/PNG，上限 100 张。文件使用内容 SHA-256 命名，生成独立清单；已有目标文件内容不同时停止，原文件保留。公开图片按内容地址缓存，避免切换页面时重复下载。目录和清单仅由运营者维护，网页没有上传任意文件或填写远程图片地址的入口

## 权限与持久化

- 未登录用户与成员只能读取当前全站设置
- 图片列表和修改接口只允许管理员，修改保留现有 CSRF、会话及权限检查
- 保存时比较设置版本，防止管理员之间覆盖更新；变更写入审计
- `site_appearance` 为新增的单行设置表，已有账号、调用 Key 和用量表不变；重启不会重置背景选择
- 登记文件不完整时保留最后可见背景，背景失败不阻断登录；没有图库时仍可使用原默认背景

本地预览登记用户提供的全部 10 张精选照片。实际素材及清单保存在忽略目录，后续更新云端时需单独迁移图库；本次本地开发未修改云端和模型服务

## 一次性邀请码

管理员在「成员与权限 → 邀请码」生成并复制，完整码只显示一次。每个码生成后24小时失效，只能注册一个普通成员，服务端仅存摘要。注册时选填有效码可直接开通，默认获授全部当前登记模型、累计不限额且继续记账；不填邀请码仍需审批，填无效或过期码会提示错误，不会创建账号

消费邀请码和创建账号在同一事务中完成，防止并发重复使用。邀请码不会授予管理员或模型启停权限；邀请码记录仅管理员可查看，不展示完整码或摘要

# 模型工作台前端 · 2026-10-22

本文记录 v0.2 的设计基线；用户后续要求更多装饰、固定桌面布局和账户使用引导，已在 v0.3.0 调整，现行行为见 [工作空间与引导](workspace-guide.md)。

目标：面向项目组共享模型的简约工作空间，保留现有后端接口、权限、额度和模拟边界。

用户指定 [PBL-new-class / pbl-pixel-course](https://github.com/shrrrrrrrr/PBL-new-class/tree/main/skills/pbl-pixel-course)。已阅读其视觉、前端接入和验收规范，查看校园选课参照图；按用户明确要求降低场景和像素装饰密度，采用奶油纸面、海军蓝、青绿点缀、近方形控件、小面积硬边像素图形。没有复制校园场景图、课程人物或学校标识，没有生成新图片。

字体使用技能包自带 ChillReunion Round v2.700，静态 weight 500，禁用合成粗体/斜体，原始 WOFF2 字节未修改。字体来源：[ChillReunion v2.700](https://github.com/Warren2060/ChillReunion/releases/tag/v2.700)，Copyright (c) 2023 ChillType，采用 SIL OFL 1.1；许可随字体保存在 `gateway/static/fonts/OFL.txt`。SHA256 为 `4f4e36dd0601c5fa325c6634649494767e9e7a0da8cc7b1fc9496ba1f7438288`。公开文件扫描只放行这一个路径与指纹匹配的二进制，其他二进制仍拒绝。

页面调整：左右分区登录、浅色侧栏与线性导航图标、概览引导与真实接口指标、统一表格/表单/状态样式、客户端接入指南。概览登记数量读取 API，不虚构实时 GPU 在线数；模型健康保持未知。接入指南说明非流式/工具协议限制，不回显 Key；复制按钮只复制当前站点 API 地址。

响应式：窄屏抽屉导航、Escape 与点击外部收起、表格横向滚动、单列表单、长地址换行；可见键盘焦点与跳转主内容链接、44px 点击目标、减少运动支持。私有工具地址仍仅在忽略目录，平台 Key 不转发给工具网站。

回退：前一版可从 Git 历史恢复静态文件；无数据库迁移，无运行控制改动。真实页面截图与字体渲染需浏览器工具可用后复核，不以静态检查替代视觉验收。

本次检查：23 项后端回归测试通过；JavaScript 语法检查通过；8 个视图通过实际本机模拟 API 返回值的渲染检查（使用最小 DOM 替身，非浏览器排版测试）；字体 HTTP 200、MIME 与原始指纹一致；临时验证 Key 已吊销。浏览器工具因缺少组件无法连接，未完成截图、实际视口和交互验收。

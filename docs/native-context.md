# 原生上下文检查（v0.10.1）

`--native-context` 是 `serve --cloud-api` 的显式选项，默认关闭。仅用于已经验收 `/apply-template` 和 `/tokenize` 的固定 llama.cpp 引擎；不是任意 OpenAI 服务的通用能力。云端源码升级不会自动启用此选项，也不会启动或重启模型。

启用前，使用合成文本与工具往返对照实际生成的 `usage.prompt_tokens`，核对模板、特殊 token、工具 schema 和历史消息；仅收到分词接口的 HTTP 200 不代表计数已与真实生成一致。模型、模板或启动配置变化后应重新验收。当前实现固定按每槽 16384 上下文检查，不自动采用模型宣传的最大上下文。

执行流程：

1. 先检查成员和 Key 的权限、任务归属，以及完整请求不超过 256 KiB
2. 在受限推理槽中，向固定 loopback 引擎核对模型身份，发送与生成相同的规范化文本、历史、工具和参数到 `/apply-template`
3. 对返回模板调用 `/tokenize`，设置 `parse_special=true`、`add_special=false`；分词数量加最大输出和 512 token 余量必须不超过 16384
4. 完成检查后重新通过原子准入检查，再提交生成；用量仍以生成结果的真实 usage 结算，不冻结新请求的额度

两个辅助请求均限时 12 秒、响应限制 2 MiB、无重试、无代理环境或重定向，只使用固定引擎凭证。辅助接口不暴露为平台公网路由，不允许调用方填写辅助接口地址，不保存渲染模板或 token 数组。不支持或异常时拒绝生成，不能静默回退到字节估算。

错误契约：

| HTTP | code | 结果 |
| --- | --- | --- |
| 400 | `context_length_exceeded` | 输入加输出与余量超过容量，未提交生成 |
| 413 | `request_too_large` | 请求超过大小限制，未提交生成 |
| 503 | `context_budget_unavailable` | 模板或分词检查失败，未提交生成 |

已有请求的幂等重放不重新分词或生成。取消、鉴权变更、限额和未知结果对账仍沿用统一任务队列；不自动重发生成请求，也不截断法律材料。流式请求在输出第一个模型片段前完成同样检查。关闭此选项时沿用旧的保守字节检查，其他上游适配器不受影响。

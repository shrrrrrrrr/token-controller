# 模型预约与站内通知 · 本地 MVP 规格

成员查看不含他人姓名、用途或正文的排队概览，申请获授权模型的时间窗；管理员审批、调整显示顺序和北京时间窗口；成员收到个人站内通知并可取消预约。审计员只读概览，不申请。队列是资源预约管理，不是推理执行器。

状态：pending → approved / rejected / cancelled；approved → approved（调整）/ closed（人工结束）/ cancelled。结束状态不再编辑。批准单一共享资源窗口时检查重叠；不承诺准确开始时间。管理员修改需版本号和理由，避免覆盖并发修改。

本期不自动切换模型、不执行预约内容、不存储提示词或上传文件、不冻结调用额度，不提供服务端 harness 或真实执行进度。申请时明确：无需一直登录网页；客户端型 Agent 真正执行时必须保持其后台进程和所需网络可用，网页登录不等于 harness 在线。服务端离线执行尚未实现。

数据：增加兼容的 model_requests / notifications 表及索引，不删除或改写已有业务表。修改前通过 SQLite backup API 备份到忽略目录；保留旧数据。失败可回退旧代码，新表暂留，不做删除式回滚。

安全：用户与 Key 模型交集、请求幂等、每用户最多3个未结束预约/每天20次申请、全局最多100个未结束预约；所有通知按当前账户读取和已读，管理员无通知内容绕过入口。其他成员只能查看队列公共字段。时间有限且数值合法，状态/优先级等只接受白名单字段。审批与通知、审计在同一个短事务内提交，事务里不调用模型或网络。

验收：成员间归属隔离、审计员和操作员无审批权、重复申请不重复通知、重叠窗口拒绝、并发版本冲突、取消/结束不触发运行操作、通知已读归属、旧库升级保留账号、页面北京时间和客户端要求提示。页面可见时每10秒轮询队列与通知计数；页面隐藏/退出停止，不丢失未提交输入。

本次证据：35 项测试通过，四角色 DOM 交互检查通过，公开树扫描无发现。浏览器工具不可用，未做真实视口/截图验收。代码更新及预约确认均未连接 GPU 或配置公网；预览 text/runtime 仍为 simulation。

# 固定工作空间与角色引导 · v0.3.0

## 布局

桌面宽度至少 1000px、高度至少 650px 时，外层固定为视口高度，导航、页头和页脚不随页面上下移动。原有长页面拆为功能页签；切换页签移动现有 DOM，不重新生成表单，保留未提交输入。表格按面板可用高度分页，长输出、复杂表单和外部工具允许区域内滚动，不裁掉内容。

小屏、短屏和浏览器放大后的 CSS 视口低于阈值时恢复可访问布局。此设计减少整页滚动，不承诺所有屏幕、无限长度回复或外部网站完全不滚动。真实桌面尺寸仍需浏览器验收。

装饰为本项目原创 SVG：像素建筑轮廓、线路、节点与光点，作为不接收点击的背景层。没有复制学校标识或未确认许可的场景图。正文保留稳定阅读层。

## 引导接口与账户行为

- `GET /api/guide`：需要有效 Bearer Key，返回当前用户角色的步骤、可见页面、当前 Key 与用户共同获授模型、模拟边界、版本和更新说明。
- `POST /api/guide/ack`：请求体只有 `version`。记录当前账户对当前角色和版本的阅读确认；相同确认幂等，其他身份字段拒绝，旧版本返回 409。
- 引导版本与页脚来自 `gateway/release.py` 的同一个 `UI_VERSION`。登录时未确认则先显示引导；角色或版本改变会重新提示。其他已登录页面保持工作位置，通过“使用引导”上的更新标记提示。
- 阅读状态通过已有审计表按用户 ID、角色、版本记录。同一账户换 Key 后沿用；不使用包含 Key 的本地存储，不需要数据库结构迁移。引导接口不会触发模型探测、调用、启停或配置变更。

| 角色 | 引导重点 |
|---|---|
| 管理员 | 成员与 Key、模型/profile 权限、预算、运行演练、对账 |
| 运行操作员 | 资产核验、获授 profile 演练、排空与记录；不能改成员/预算/策略 |
| 普通成员 | 授权调用、自己任务和用量、重试 ID、客户端连接与工具 |
| 审计员 | 只读资产/运行/账本/审计；不能调用模型或执行管理写操作 |

菜单和按钮按角色提示，实际授权继续由原后端执行。模拟视频、未知健康状态、尚未上线的预约/夜间切换/真实 GPU 执行器均明确说明。

## 后续版本必须同步

更新前端或用户可见功能时，一起审阅 `gateway/guide.py` 中的四角色说明，更新 `gateway/release.py` 的版本及变更记录，并运行：

```powershell
.\.venv\Scripts\python.exe tools/check_guide_sync.py
.\.venv\Scripts\python.exe -m pytest -q --basetemp=.state/pytest
```

第一条检查相对 HEAD 的候选变更是否同时包含引导和新版本。交付后的复核可用 `--base` 指定更新前提交；它检查同步维护约定，不能自动判断所有说明是否准确，仍需人工审阅。第二条包含角色隔离、同账户多 Key、幂等确认、角色变更和版本升级回归。

本次验证：29 项后端测试通过；DOM 解析检查覆盖四角色首次登录、引导步骤、可见页面、页签切换、输入保留及分页。装饰和工作区 CSS 的 HTTP 资源检查通过。DOM 解析不计算 CSS 布局；浏览器工具因缺少组件无法连接，截图、真实视口及无整页滚动效果尚待实测。
